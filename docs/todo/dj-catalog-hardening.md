# DJ catalog and mobile playback

**Status:** partial

Desktop library key notation (musical, Camelot, Open Key), mixable-track search on the existing smart-playlist evaluate command, tap tempo, half/double BPM, a Prepare playlist (`P`), and copying the last listening session as a tracklist. Mobile: lock-screen seek and stop, reload a failed stream when the network returns, and safe-area padding on the shell and drawers. The user manual page is `packages/docs/user-manual/desktop/mixing.md`.

Still open (needs the Rust catalog, which this environment could not build): hot cues, beatgrid, energy, Rekordbox/Serato/Traktor collection import. Real-library check of mixable results is still manual. The todo stays until that Rust work lands.
