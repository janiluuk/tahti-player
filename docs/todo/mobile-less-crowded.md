# Mobile: full width, fewer controls, less crowded

**Status:** open

Requested 2026-11-24.

## Plan

- [ ] Use the whole screen width on phones: audit page gutters, nested card padding and max-width wrappers.
- [ ] Track lists: no selection checkbox on phones by default (selection mode on demand).
- [ ] Reduce crowding: fewer inline icon buttons per row, move secondary actions into the row menu, check toolbars that wrap into several rows.
