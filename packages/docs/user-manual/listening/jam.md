# Listen together (Jam)

A Jam is a shared listening session: everyone in it hears the same queue at the same time.

## Start a Jam

1. Open a public playlist or collection (yours under **Library → Collections**, or anyone's public one).
2. Choose **Start a Jam**.
3. Share the `/jam/<code>` link. Guests join in their browser.

The host controls play, pause and the queue, unless they give a guest co-control. When the host ends the Jam, everyone returns to Listen. An ended or wrong code shows an error on the Jam page.

{% hint style="info" %}
**Tahti Jam** in the desktop app is something else: a phone remote for the desktop player on your own network. See [Remote control](../desktop/remote-control.md).
{% endhint %}
