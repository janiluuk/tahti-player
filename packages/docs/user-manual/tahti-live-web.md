# Tahti Live (web)

The web app at [beta.tahti.live](https://beta.tahti.live) (and later tahti.live) is the Listen / Studio / Admin client. It shares themes and many player ideas with the desktop app, but the chrome and workflows are different.

## Main chrome

| Sidebar | What it is |
| --- | --- |
| **Listen** | Home: continue listening, who’s on air, Disco-widgets. In-page tabs for Feed and History. |
| **Radio** | Tahti Radio station page. Use the calendar control for the full programme schedule, or book a slot when signed in. |
| **Discover** | Arranged widgets, artists directory, venues. |
| **Favorites** | Saved channels, radio, and tracks. |
| **Library** | Your tracks, collections, uploads, stash, embeds, smart links (signed in). |
| **Studio** | Artist tools (overview, stats, posts, audience, releases, editor, broadcast). Listeners see “Become an artist” instead. |
| **Admin** | Board-only platform ops. |
| **Help center** | In-app user guide (preferred over this page for web how-tos). |
| **Settings** | Account, channel, broadcast, themes, add-ons, integrations. |

On phones, Listen / Discover / Radio (and Studio when you are an artist) sit in the bottom bar; Favorites, Library, Help, and Settings live under More.

## Where the detailed guide lives

Open **Help center** in the web app for listener, artist, broadcast, releasing, and admin articles. That guide stays in sync with the product. This GitBook page is only a map of the chrome.

## Shared listening vs desktop remote

- **Shared Jam** — Start a Jam on a public playlist/collection; guests join via `/jam/$code`. See Help → Shared listening (Jam).
- **Desktop Tahti Jam** — Phone remote for the desktop player on your LAN. See [Remote control](remote-control.md).

## Desktop player docs

Installation, plugins, queue, favorites, themes, and keyboard shortcuts in the rest of this manual describe the **desktop** Tahti Player app unless a page says otherwise.
